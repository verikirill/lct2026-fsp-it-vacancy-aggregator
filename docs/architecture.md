# Архитектура

```
браузер -> web (Vue 3, Vite) -> api (FastAPI) -> PostgreSQL
                                   |
                                 Redis <- worker (Celery beat + worker)
                                              |
                                  hh.ru API, API ФСП
```

## Компоненты

- **api**: REST на FastAPI, модели SQLAlchemy, схемы Pydantic.
- **worker**: Celery, раз в 30 минут забирает вакансии hh.ru по ИТ-ролям и
  складывает в таблицу `vacancies`.
- **web**: SPA на Vue 3 с Pinia и vue-router.

## Данные

| Таблица | Что хранит |
| --- | --- |
| users | участник, навыки строкой через запятую, рейтинг ФСП |
| achievements | места на соревнованиях, уровень, ссылка на подтверждение |
| vacancies | вакансии из hh.ru, Хабр Карьеры и SuperJob |

## Рейтинг ФСП

Рейтинг считается по Эло: стартовое значение 1200, K = 32, вес уровня соревнования
1,0 для регионального, 1,6 для всероссийского и 2,2 для международного.

## Рекомендации

TF-IDF по навыкам участника и вакансии, косинусная близость и бонус 15% от
нормированного рейтинга ФСП. Топ-20 вакансий отдаётся в `/api/matching/{user_id}`.
